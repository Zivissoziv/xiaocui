# ADR-001: 一期优先做表单来源适配，而不是自研表单

## 状态

建议采纳

## 背景

企业内已经可能存在 OA、问卷系统、飞书/钉钉表单、共享 Excel、业务系统填报页等多种信息收集入口。催办痛点主要发生在“知道谁没填、何时催、催到什么程度、如何留痕”，而不是每次都缺一个表单搭建器。

## 决策

一期不自研完整表单搭建能力，而是把外部表单、Excel/CSV 和接口同步统一抽象为 `FormSource`。催办工具只要求拿到应填对象、填写入口和状态数据。

## 影响

好处：

- 降低一期建设成本。
- 更容易嵌入现有企业流程。
- 避免与已有 OA 或问卷系统重复建设。
- 能快速验证催办自动化是否真正减少人工跟进。

代价：

- 对外部系统状态同步能力有依赖。
- 不同表单来源的数据质量和字段标准不一致。
- 对填写内容的完整性校验能力有限。

## 后续条件

当至少 3 类高频任务都需要相同的字段、校验、退回补充流程时，再评估内置轻量表单能力。
